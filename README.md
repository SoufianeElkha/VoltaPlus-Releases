# VoltaPlus — téléchargements

Logiciel de devis de tableaux électriques, pour Windows 10 et 11 (64 bits).

**Télécharger** : ouvrez [la dernière version](https://github.com/SoufianeElkha/VoltaPlus-Releases/releases/latest)
et prenez le fichier `VoltaPlus-Setup-x.y.z.exe`.

Au premier démarrage, un essai de 7 jours commence. Pour continuer, transmettez
à l'éditeur le « Code de ce poste » affiché par le logiciel : il vous enverra
votre clé de licence.

VoltaPlus se met à jour de lui-même : quand une version paraît, un bandeau la
propose.

Les fichiers `revocations.sig` et `version.sig` sont lus par le logiciel ; ils
sont signés par l'éditeur. Ce dépôt ne porte aucun code source.
